其它需求

序号类别内容
1数据需求 ① 注册转化漏斗：启动APP → 选择登录方式 → 发送OTP → 验证成功 → 完成注册
② KYC转化率：注册用户 → 发起认证 → 提交材料 → 审核通过
③ 登录方式分布：按手机号/WhatsApp/邮箱统计注册用户占比
④ 各国/地区注册用户数量分布
2兼容需求iOS 15+ / Android 10+；Web后台支持 Chrome 100+ / Safari 16+ / Edge 100+
3性能需求 OTP发送延迟 ≤ 5秒；制裁名单校验 ≤ 3秒；KYC OCR识别 ≤ 8秒；登录页首屏加载 ≤ 2秒
4风控需求 ① OTP防刷：同号码60秒限发1次，同IP每小时≤10次
② 连续错误5次锁定30分钟
③ 制裁名单命中即拦截注册
④ KYC材料伪造检测（OCR可信度评分）
5权限需求 Web后台角色：超级管理员 / KYC审核员 / 风控专员 / 客服（只读）
6新手引导首次注册完成后引导弹窗："Complete your profile to start trading" → 跳转个人信息页或KYC认证页
7历史数据处理方案v1.0为全新系统，无历史数据迁移
8降级方案OTP多通道降级：SMS → WhatsApp → 语音验证码；制裁名单API不可用时允许注册但标记待复查
9关联需求 商品浏览模块需读取用户登录状态（控制详情页/价格可见性）；
下单模块需读取KYC认证状态（控制下单权限）

名单同步状态展示各制裁名单最近同步时间、同步结果（成功/失败）、记录总数
手动触发同步支持手动触发某个名单的即时同步
命中记录查询展示所有命中记录（用户信息、命中名单、命中字段、处理状态）
人工复查对「疑似命中」记录进行人工判定（确认拦截 / 判定误报放行）
拦截白名单对已确认的误报用户加入白名单，后续自动跳过筛查
